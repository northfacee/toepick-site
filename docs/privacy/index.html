개인정보처리방침

시행일 및 최종 수정일: 2026년 9월 21일

northface(이하 “운영자”)는 ToePick(앱 내 표기: TOE-PICK, Android 패키지: com.toepick)의 사용자 정보를 아래와 같이 처리합니다. 이 방침은 ToePick 앱과 본 소개 웹사이트에 적용됩니다.

먼저 알아두세요

ToePick은 회원가입 없이 이용하지만, 학습을 이어가기 위해 임의로 생성한 기기별 식별자와 풀이 기록을 서버에 저장합니다. 이름이나 이메일로 가입하지 않는다고 해서 모든 데이터를 수집하지 않는 것은 아닙니다.

현재 서버 기록의 정기 자동 삭제 기능과 고정된 보관 기간은 마련되어 있지 않습니다. 앱을 삭제해도 서버 기록은 자동으로 삭제되지 않습니다.

1. 처리하는 정보와 목적

  • 기기별 서비스 식별 정보: 앱 설치에 대해 서버가 발급하는 임의 식별자, 인증 토큰의 해시값을 기록 소유권 확인과 다른 이용자의 기록 접근 방지에 사용합니다. 광고 ID, IMEI 또는 전화번호를 식별자로 사용하지 않습니다.
  • 학습 기록: 문제 세트 식별자, 생성 일시·상태, 생성된 문항, 선택한 답, 정오답, 기기의 현지 학습 날짜, 문항별 풀이 시간, 재풀이 연결 정보 및 중복 요청 방지용 식별자를 저장합니다. 채점, 이어풀기, 기록 조회, 통계와 복습을 제공하기 위한 정보입니다.
  • 기기에 저장하는 정보: 인증 토큰은 운영체제의 보안 저장소에, 학습 결과 캐시·북마크·즐겨찾기 단어·닉네임·아바타·화면 모드·로컬 알림 설정·앱 이용 상태는 앱의 로컬 저장소에 저장합니다. 기록 조회와 오프라인 복습에 사용합니다.
  • 문의 정보: 이메일로 문의할 때 보내는 이메일 주소와 문의 내용을 답변 및 요청 처리 목적으로 이용합니다. 인증 토큰이나 비밀번호는 이메일로 보내지 마세요.

현재 앱은 이름·이메일을 요구하는 회원가입, 광고, 위치·연락처·사진·마이크 수집 기능을 제공하지 않습니다. Sentry, PostHog, LogRocket의 분석·세션 재생 SDK는 현재 앱에 적용되어 있지 않습니다.

2. AI 및 외부 서비스 이용

Vercel · Supabase: 앱의 API는 Vercel에서 실행하고, 기기별 식별자·인증 토큰 해시·문제·답안·학습 기록은 Supabase PostgreSQL의 저장합니다. 생성된 듣기 MP3는 Supabase 비공개 Storage에 보관합니다. 앱은 데이터베이스에 직접 접근하지 않고 서버를 통해 본인 기록을 조회합니다. 호스팅 제공자는 요청 처리와 보안 운영을 위해 IP 주소와 접속 시각 등 기술 정보를 처리할 수 있습니다. 자세한 처리 조건은 Vercel 개인정보처리방침과 Supabase 개인정보처리방침에서 확인할 수 있습니다.

Google Gemini: 영어 문제와 한국어 해설을 만들기 위해 서버가 Google Gemini API를 호출합니다. 요청에는 문제 유형·주제·생성 지시, 중복 방지를 위한 생성 문장과 검증 오류 정보가 포함됩니다. 현재 구현에서는 기기 인증 토큰, 기기별 식별자, 이용자의 선택 답안이나 학습 이력을 문제 생성 요청에 넣지 않습니다. Google의 처리 조건은 Gemini API 이용약관에서 확인할 수 있습니다.

LangSmith: 문제 생성 과정의 입력·출력, 실행 시간, 오류 정보를 생성 품질과 장애 분석에 사용합니다. 생성 그래프에는 기기 인증 토큰과 사용자 답안을 전달하지 않습니다. LangChain 개인정보처리방침을 참고하세요.

Speechify · Cartesia: 듣기 문항의 음성을 생성하기 위해 서버가 생성된 영어 질문·보기를 음성 제공업체에 전송합니다. 신규 음성은 Speechify로 생성하며 기존 Cartesia 음성을 유지합니다. 사용자 답안이나 기기 인증 토큰은 음성 생성 입력에 포함하지 않습니다.

소개 웹사이트: 본 사이트는 GitHub Pages를 통해 제공됩니다. 페이지 제공과 보안 운영을 위해 호스팅 제공자가 IP 주소 등 접속 과정의 기술 정보를 처리할 수 있습니다. 사이트 자체에는 회원가입 폼, 광고 또는 별도의 방문 분석 도구를 설치하지 않았습니다. 호스팅 서비스의 처리는 GitHub 개인정보처리방침을 참고하세요.

위 외부 서비스는 서비스 구성에 따라 대한민국 외 지역에서 정보를 처리할 수 있습니다. 향후 서버 호스팅·저장소 또는 분석 서비스의 실제 운영 구성이 바뀌어 사용자 정보 처리 범위가 달라지면 이 방침을 갱신합니다.

3. 보관 기간과 삭제

서버의 기기 식별 정보와 학습 기록: 현재 학습 기록 조회와 이어풀기를 위해 저장되며, 정기 자동 삭제나 고정 보관 기간은 설정되어 있지 않습니다. 별도 삭제 처리가 이루어지기 전까지 서버에 남을 수 있습니다.

기기의 캐시·북마크: 운영체제의 앱 데이터 삭제 또는 앱 제거 기능으로 삭제할 수 있습니다. 보안 저장소의 인증 정보는 운영체제·백업 설정에 따라 유지될 수 있으며, 앱 제거가 서버 데이터 삭제를 의미하지는 않습니다.

이메일 문의: 문의 답변과 요청 처리에 사용합니다. 현재 문의 메일의 정기 자동 삭제 기간은 정해져 있지 않습니다. 관련 메일의 삭제를 원하면 아래 연락처로 요청할 수 있습니다.

현재 앱 내 전체 기록 삭제 버튼이나 자동 삭제 API는 없습니다. 서버 기록의 열람·정정·삭제 또는 처리 정지를 원하면 jkgjms2@gmail.com으로 요청해 주세요. 운영자는 요청 대상 기록을 식별하고 소유권을 확인하기 위한 방법을 안내합니다. 익명 기기 기반 서비스 특성상 앱 제거 등으로 식별 수단을 잃은 경우 해당 기록을 찾거나 소유권을 확인하는 데 제한이 있을 수 있습니다.

4. 정보 보호

인증 토큰 원문은 서버 데이터베이스에 저장하지 않고 해시값으로 검증합니다. 서버는 각 요청에서 기록 소유권을 확인합니다. 기기에서는 운영체제의 보안 저장소에 인증 토큰을 보관합니다. 사용자의 정보에 접근할 수 있는 범위를 서비스 운영에 필요한 범위로 제한합니다.
